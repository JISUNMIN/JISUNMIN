최근에는 LogRocket 기반 운영 오류 분석과 SQL을 활용한 데이터 보정 업무를 수행하고 있으며, Codex · ChatGPT를 코드 분석, 리팩토링, 브라우저 테스트 및 문서화에 활용하고 있습니다.
